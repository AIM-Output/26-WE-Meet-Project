## 배치 규칙 (F8 5절 ②·③)

### ① 해야 할 것 — 과제 · 할 일

| 작업 | 길이 | 언제까지 |
|---|---|---|
| F7 과제 | F7 필요 시간(예상 소요 × 안전계수) − 이미 해 둔 블록 | 과제 마감 시각까지 (R11) |
| C1 할 일 (날짜만 있는 미완료) | 30분 | 그 날짜의 낮 끝까지. **날짜가 지난 할 일(2주 안)은 '밀린 할 일'**로 기간 안 가장 이른 공강 |

- 시각이 있는 할 일은 그 시각에 이미 있으므로 넣지 않는다(차지된 시간으로 뺀다).
- **순서**: F7 이 준 순서 그대로. 할 일은 같은 잣대(여유 = 기한 − 지금 − 길이)로 그 사이에 끼운다.
- **채우기**: 이른 공강부터. 블록 최대 2시간·최소 30분, 같은 공강 안에서는 이어 붙인다(3시간 과제 → 2시간 + 1시간).
  남는 시간이 30분보다 짧게 남지 않게 앞 블록을 줄인다(130분 → 100 + 30).
- **같은 작업은 하루 2블록까지**(R16) — 고정해 둔 블록도 센다.
- 이미 해 둔 시간 = 완료 체크 + 내가 옮긴(고정) + 진행 중인 블록. 지나갔는데 체크하지 않은 자동 블록은 한 것으로 치지 않는다.
- 마감이 기간(기본 7일) 뒤인 과제의 남은 시간은 실패가 아니라 **다음 배치로 미룬다**(`deferred`).

### ② 남는 공강 → 공부 블록 (2026-10-07, 설정 `fillStudy` 기본 켬)

과제·할 일을 다 넣고 남은 공강을 앞에서부터 메우며, 매번 **점수가 가장 높은 시험(과목)**을 고른다.

```
점수 = 남은 진도율(1 − 진도%) ÷ 시험까지 남은 날수(그 블록 날짜 기준, 시험 당일은 0.5일)
       × 0.5^(그 날 이미 넣은 같은 과목 블록 수)          ← 한 과목만 하루 종일 하지 않게
```

- 대상은 F5 의 **30일 안 시험**(발표 제외)이고, 진도율은 F5 과목 카드의 공부 진도(체크한 자료 + 계획에서 완료한 블록, D10).
- 진도 100% · 지난 시험은 빼고, 같은 과목은 하루 2블록까지. 시험 당일은 시험 시작 전(여유 포함)까지만, 시각 미정 시험은 당일 제외.
- 동점이면 시험이 빠른 것 → 과목명 → id. 미리보기에 오늘 기준 순서(`studyTargets`)를 그대로 보여 준다.
- 공부 블록은 채우기라 미리보기에서 빼도 미배치로 적지 않는다 — 그 공강이 빈 채로 남는다.

### 블록 근거 한 줄 (F8-R22)

| 작업 | 예 |
|---|---|
| 과제 | `소프트웨어공학론 · 10/2 18:00 마감 · 5시간 중 2시간 · 공강 180분` |
| 할 일 | `9/29 할 일 · 공강 60분` · `9/25 할 일 (밀린 할 일) · 공강 60분` |
| 공부 | `남은 진도 50% · 시험 D-2 · 공강 180분` · `남은 진도 100% · 11:00 시험 전 · 공강 120분 · 임의 일정` |

### 미배치 이유

| 키 | 문구 |
|---|---|
| `noSlot` | 마감까지 빈 공강이 없습니다 |
| `short` | 30분 이상 연속 공강이 없습니다 |
| `overdue` | 이미 마감이 지났습니다 (2주 안의 놓친 마감만) |
| `sameTask` | 같은 작업은 하루 2블록까지라 남았습니다 |
| `excluded` | 미리보기에서 뺐습니다 |

미배치가 있으면 조정 제안 최대 3개: **낮 시간 늘리기**(시작을 1시간 앞으로, 07:00 까지 · 그다음 끝을 19:00 까지) · **주말 켜기** · **점심 시간도 쓰기**.

## 등록 · 고정 · 충돌

- **등록은 미리보기 시각(`at`)으로 다시 계산해 `signature` 가 같을 때만** 한다 — 그 사이 수업·일정·마감이 바뀌었으면 409(8절). 30분 넘게 지난 미리보기도 409.
- 다시 배치하면 **자동 배치분(앞으로 · 미완료 · 고정 아님)만** 바뀐다. 내가 옮긴 블록(`placedBy: user`)·완료·이미 시작한 블록은 그대로(R30·R33).
- 캘린더에서 블록을 끌어 옮기면 **고정**된다(`자동` 칩이 사라진다). 상세에서 `고정 풀기`.
- 충돌(R31) — `/api/events` 의 블록에 `extendedProps.conflict` 한 줄: `○○ 수업과 겹칩니다` · `'스터디' 일정과 겹칩니다` ·
  `다른 학습 블록과 겹칩니다` · `끝낸 과제/할 일입니다` · `시험이 지났거나 진도를 다 채웠습니다` · `마감 뒤에 있습니다` · `시험 뒤에 있습니다`.
  앞으로 남은 블록이 있을 때만 다른 일정을 읽는다. 캘린더는 저절로 고치지 않는다 — `재배치 제안 보기`로 미리보기를 연다(R32).
- 블록 id 는 `pb:<n>`. 공부 블록은 시험 날짜·유형을 `extra` 칸에 함께 저장한다(공부 캘린더가 쓴다, 옛 DB 는 열릴 때 칸이 더해진다).

## API (대시보드 백엔드가 붙인다 — Frontend-Route 13-6)

| 메서드 · 경로 | 내용 |
|---|---|
| `POST /api/placement/preview` | `{range?, exclude?, settings?}` → `days`(격자) · `blocks`(taskType assignment·todo·study) · `kept` · `unplaced` · `deferred` · `dailyTotals` · `studyTargets` · `studyMinutes` · `adjustments` · `existing` · `state` · `signature` · `at` |
| `POST /api/placement` | `{signature, at, range?, exclude?}` → 등록 (`409` = 다시 계산) · `created` · `studyCreated`(공부 캘린더로 간 수) |
| `GET /api/placement/conflicts` | 겹친 블록 + 배너 문구 |
| `GET /api/placement/today` | 오늘 블록 + 한 줄 — F10 아침 브리핑 · F9 대화 |
| `DELETE /api/placement?from=&to=` | 기간 안의 자동 배치 블록만 지우기 |
| `PATCH /api/placement/blocks/{id}` | `{start, end}` 옮기기(→ 고정) · `{done}` · `{fixed: false}` |
| `DELETE /api/placement/blocks/{id}` | 블록 하나 지우기 (공부 캘린더의 삭제도 이것) |
| `GET · PUT · PATCH /api/settings/availability` | 공강 배치 설정 (`null` = 그 칸 기본값, `{reset: true}`) |
| `/api/events` 의 `kind=study` | 등록된 **과제·할 일** 블록 — `taskType · placedBy · auto · reason · refId · done · conflict` (공부 블록은 없다) |
| `/api/status` 의 `placement` | 앞으로 남은 블록 · 오늘 블록 · `updatedAt`. 1분마다 불리므로 다른 일정을 읽지 않는다 |
| `api.study_blocks(start, end, …loaders)` | 경로 없음 — 백엔드가 F5 공부 캘린더(`/api/study-calendar`)에 공강 공부 블록으로 넘긴다(`conflict` 포함). 공부 블록이 나오는 곳은 여기뿐 |

저녁 시간대 설정은 F5 의 `GET·PUT /api/exams/settings {evening: {start, end}}` 에 있다(화면은 같은 '가용 시간' 페이지).
