# 유니버스(Univ-Us) — 사용 안내

전남대 e클래스에서 **내 과제·마감·강의자료를 자동으로 모아** 내 PC 의 앱(캘린더·할 일·학사일정·졸업요건·출결·시험 공부)에 보여 주는 프로그램입니다.
모든 것이 **내 컴퓨터 안에서만** 돕니다. 비밀번호·강의자료·로그인 세션은 어디에도 올라가지 않습니다.

> 이 문서는 **설치해서 쓰는 사람**을 위한 안내입니다. 코드를 고치거나 설치 파일을 만들려면 → [DEVELOPMENT.md](DEVELOPMENT.md)

막히면 [문제 해결](#문제-해결) 을 먼저 보고, 그래도 안 되면 팀 채팅에 **화면을 캡처해서** 올려 주세요.

---

## 1. 설치

**[최신 버전 받기 (GitHub Releases)](https://github.com/AIM-Output/26-WE-Meet-Project/releases/latest)** — 프로그램을 따로 설치할 필요 없이 파일 하나면 됩니다.

### Windows 10/11
1. `UnivUs_…_x64-setup.exe` 를 받아 실행합니다. 관리자 권한은 필요 없습니다(내 계정에만 설치).
2. **"Windows의 PC 보호"** 파란 창이 뜨면 **추가 정보 → 실행** — 아직 코드 서명을 하지 않아서 뜨는 경고입니다.
3. 시작 메뉴의 **UnivUs** 로 엽니다.

### macOS (Apple Silicon — M1 이후)
1. `UnivUs_…_aarch64.dmg` 를 열고 **UnivUs** 를 **응용 프로그램** 폴더로 끌어 넣습니다.
2. 처음 열 때 "확인되지 않은 개발자" 로 막히면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**.
3. 인텔 맥용은 아직 없습니다.

### 새 버전이 나오면
같은 페이지에서 새 설치 파일을 받아 그대로 설치합니다(덮어쓰기). **내 데이터·로그인은 그대로 남습니다.**
설치하기 전에 트레이(작업 표시줄 오른쪽 아래)의 유니버스 아이콘 → **종료** 를 먼저 눌러 주세요.

## 2. 처음 설정 (5분)

처음 실행하면 학교 로그인에 쓰는 **브라우저 엔진(약 150MB)을 자동으로 받습니다.** 그동안 로그인 버튼은 "내려받는 중"이라고 답하니 몇 분 기다려 주세요.

| 순서 | 어디서 | 무엇을 |
|---|---|---|
| 1 | 처음 나오는 **첫 설정** 화면 | 학과 → 입학년도·이수유형 → (선택) 학사정보시스템에서 가져오기 |
| 2 | ⚙ → **수집 원천 → e클래스 → `로그인 창 열기`** | 뜨는 창에서 [SSO 로그인] → 포털 아이디/비밀번호 → **휴대폰 2차 인증** 승인 ("이 기기를 신뢰" 가 있으면 켜기). e클래스 메인까지 들어가면 창이 저절로 닫히고 바로 수집합니다 |
| 3 | 같은 줄 **`자동 로그인 정보 저장`** (선택, 권장) | 아이디·비밀번호를 **이 PC 에만 암호화해** 저장 → 로그인이 만료돼도 창 없이 다시 로그인 (Windows: 이 계정에서만 풀림 / 맥: 로그인 키체인) |
| 4 | e클래스 · 학사일정 줄의 **예약 실행 `켜기`** | e클래스는 정각 4시간마다, 학사일정은 매일 08:00 — 창 없이 자동 수집. PC 가 꺼져 있었으면 켜지는 대로 따라잡기 |

첫 수집은 자료 양에 따라 **몇 분 ~ 십여 분** 걸립니다(학교 서버 부담을 줄이려고 천천히 받습니다). 두 번째부터는 빠릅니다.

> 수집하지 않는 것: 동영상 본체, 퀴즈 문제(마감 일시만)·출석, 학생들이 글을 쓰는 게시판(Q&A·팀빌딩 등). 학교 저작권 안내를 지키기 위한 설계입니다.

## 3. 화면

| 메뉴 | 기능 |
|---|---|
| 대시보드 | 오늘 브리핑 · 캘린더(e클래스 마감·내 일정·할 일·학사·수업·공강 블록) · 먼저 할 것 · 할 일 · 기능 타일 |
| 학사일정 | 학교 학사일정·학사공지 → 캘린더 자동 등록, 확인 필요 일정, 원문 보기 |
| E클래스 | 과제·동영상 마감(내가 체크함·소요시간) · 공지·자료 새 글 · 과제 우선순위(지금 해야 함 / 이번 주 / 나중에) |
| 졸업요건 | 영역별 이수·남은 학점 (학사정보시스템 기이수성적 가져오기) |
| 출결 | 시간표 → 수업 회차, 결석 한도·학사경고 예방, 휴강 자동 반영 |
| 강의자료 | 받은 자료를 과목·주차별로 열기 · 파일 끌어다 추가 |
| 시험·발표 | 공지에서 시험 찾기 → 분량을 날짜로 나눈 공부 계획 · 공부 체크 · 공부 캘린더 |
| 설정 | 내 프로필 · 수집 원천(로그인·자동 로그인 정보·예약 실행) · 졸업요건 기준 · 가용 시간 · 알림 |
| 기회 · 팀플 · 브리핑 · 대화 | 🚧 아직 예시 데이터 (화면만) — "예시 데이터" 띠가 보이는 화면 |

- **창을 닫으면 트레이로 숨습니다** — 예약 수집·마감 알림은 계속 돕니다. 완전히 끄려면 트레이 아이콘 → **종료**.
- 트레이 메뉴의 **로그인할 때 실행** 을 켜 두면 PC 를 켤 때 창 없이 함께 켜집니다.
- 학교 사이트로 가는 링크(원문 보기·e클래스에서 열기)는 **기본 브라우저**로 열립니다.

## 4. 내 데이터 · 절대 하지 말 것

데이터는 이 PC 에만 있습니다 — Windows `%LOCALAPPDATA%\kr.univus.desktop\data` · 맥 `~/Library/Application Support/kr.univus.desktop/data`.
앱을 지울 때(설정 → 앱 → UnivUs 제거) **"앱 데이터 삭제"** 를 고르면 이 폴더도 지워집니다.

| ❌ 금지 | 이유 |
|---|---|
| 데이터 폴더(특히 `C3_Login_agent/state`)를 복사·공유·업로드 | **내 계정으로 로그인된 상태**(세션, 암호화된 비밀번호)가 들어 있음 |
| `F6_Eclass_agent/data` · `F4_Textbook_agent/data` 를 남에게 전송·클라우드 업로드 | 학교 강의자료 — 학교 저작권 안내상 **타인 배포·인터넷 게시 금지** |
| 다른 기능의 데이터 공유 | 내 일정·프로필·**성적(이수 내역)**·출결·시험 계획 = 개인정보 |
| 다른 사람 PC 에서 내 계정으로 로그인 | 계정정보 공유 = 학교 금지 사항 |

## 문제 해결

**Q. 설치 파일을 실행하면 "Windows의 PC 보호" 가 떠요 / 백신이 막아요**
아직 코드 서명을 하지 않은 프로그램이라 뜨는 경고입니다. **추가 정보 → 실행**. 백신이 격리했다면 [Releases](https://github.com/AIM-Output/26-WE-Meet-Project/releases) 에서 받은 파일인지 확인한 뒤 예외로 허용하세요.

**Q. 맥에서 "손상되었기 때문에 열 수 없습니다" 가 떠요**
터미널에서 `xattr -cr /Applications/UnivUs.app` 를 한 번 실행한 뒤 다시 여세요 (인터넷에서 받은 서명 없는 앱에 붙는 표시를 지우는 것).

**Q. 로그인 버튼이 "브라우저 엔진을 내려받는 중" 이라고만 해요**
처음 실행 때 약 150MB 를 받는 중입니다. 몇 분 뒤 다시 누르세요. 30분이 지나도 그대로면 앱을 종료(트레이 → 종료)하고 다시 실행하세요 — 받다가 끊긴 것을 다시 받습니다.

**Q. 로그인 창이 떴는데 10분 안에 못 끝냈어요 / 창을 실수로 닫았어요**
**로그인 창 열기** 를 다시 누르면 됩니다.

**Q. 수집이 "로그인 필요" 로 멈춰요**
로그인이 만료됐고 자동 재로그인도 안 된 것입니다. **로그인 창 열기** (휴대폰 인증 한 번). 자동 로그인 정보를 저장해 두면 대부분 생기지 않습니다. 학교 비밀번호를 바꿨다면 **자동 로그인 정보 바꾸기** 로 다시 저장하세요.

**Q. 수집이 "네트워크 오류" 로 멈춰요**
예약 실행이면 5·15·45분 뒤 스스로 다시 시도합니다. 학교 와이파이 방화벽이면 다른 네트워크에서 시도해 보세요.

**Q. 앱 창이 시작 화면에서 "로컬 서버가 멈췄습니다" 로 멈춰요**
트레이 → 종료 후 다시 실행. 그래도 같으면 데이터 폴더의 `logs/backend.log` 를 캡처해서 팀 채팅에.

**Q. 다른 PC 에서도 쓰고 싶어요**
그 PC 에 새로 설치하고 로그인·2차 인증을 다시 하면 됩니다. 데이터 폴더를 복사해 가지 마세요 — 저장한 비밀번호는 그 PC·계정에서만 풀립니다.
