# F3_Attendance_agent — 출결·학사경고 예방 알림 (유니버스 F3)

과목마다 **이번 학기 수업이 몇 번인지 자동으로 세고**, 내가 빠진 것을 기록해 **1/4 한도에 닿기 전에** 경고한다.
요구사항은 [요구사항정의서.md](../요구사항정의서.md) F3 절, 화면·라우트는 [Frontend-Route.md](../Frontend-Route.md) 8절.

> **학교 공식 출결 기록이 아니다 — 내가 입력한 값 기준.** (F3 10절 '신뢰 고지' — 모든 화면·명령줄 출력에 붙인다)

- **단위는 회 = 수업한 날 하나** (2026-09-29 수정). 전남대는 출석을 하루 단위로 부른다 — 월 5·6교시든 수 5교시든 그날 1회.
- **계산은 규칙 기반 코드 하나**(`attendance/calc.py`)뿐이다. LLM 을 쓰지 않는다 (F3-R37).
- **설치할 것이 없다** — 전부 표준 라이브러리. 시간표 조회도 로그인이 필요 없는 공개 화면이라 브라우저·SSO 세션을 빌리지 않는다.
- 출결 기록은 `data/attendance.db` 에만 있다. 밖으로 보내지 않는다.

## 쓰는 법

앱 대시보드 → 기능 타일 **출결** → `시간표 설정` 탭 → **`시간표 자동으로 가져오기`**.
e클래스 과목 목록(`F6_Eclass_agent/data/courses.json`)을 먼저 받아 두어야 한다(대시보드의 e클래스 동기화). 학기 범위·휴업일은 F1 학사일정에서, 휴강 공지는 e클래스 동기화가 받은 게시판 글에서 읽는다.

그다음은 `과목별 현황` 에서 과목을 펼쳐 회차마다 **출석 · 결석 · 지각 · 공결 · 휴강** 칩을 누르거나, `이번 주` 탭에서 몰아서 입력한다. 캘린더(주·목록 보기)의 수업을 눌러도 같은 기록이다.
학사일정 휴업일과 e클래스 공지의 휴강은 **휴강 칩이 미리 켜져** 있다(근거 한 줄 + 공지 링크). 틀렸으면 칩을 다시 눌러 푼다.

명령줄 (저장소 루트에서 개발 venv 를 켜고 — `desktop/cli.py` 가 개발 데이터로 `python -m attendance` 를 돌린다, `--app` 이면 앱 데이터):

```bash
python desktop/cli.py attendance status                         # 과목별 총 횟수 · 결석/허용 · 남은 여유 · 상태 · 근거 · 공지 확인 필요
python desktop/cli.py attendance import                         # 시간표 자동으로 가져오기 (공개 조회, 로그인 불필요)
python desktop/cli.py attendance notices                        # e클래스 공지에서 찾은 휴강
python desktop/cli.py attendance sessions 운영체제               # 회차 목록과 회차 id
python desktop/cli.py attendance mark "cl:74245:2026-09-07" absent     # present·absent·late·excused·none · canceled(휴강)·scheduled(휴강 풀기)
python desktop/cli.py attendance semester                       # 학기 범위 · 휴업일 · 학교 지정 보강일
python desktop/cli.py attendance parse 화5목5                    # 강의시간 해석 (시각)
python desktop/cli.py attendance clear                          # 출결 기록·시간표·설정 전부 지우기
```

테스트: 이 폴더에서 `python -m pytest tests -q` (개발 venv `desktop/sidecar/.venv`. 임시 data · 가짜 학사일정 DB · 가짜 e클래스 게시판을 쓴다 — 내 기록·학교 사이트 무접촉)

### 공지에서 휴강 찾기 (`notices.py`)

2026-09 실제 과목 공지 4건이 전부 맞게 잡힌다: 소프트웨어공학론 '9월 17일 목요일 휴강' → 9/17 · 오픈소스소프트웨어 '9월 17일 휴강 공지 / 금일 수업은 휴강' → 9/17 · 운영체제·컴퓨터네트워크 '오늘 수업 휴강(9/16)' → 9/16.

| 규칙 | 예 |
|---|---|
| '휴강'이 든 줄(제목 포함)마다 날짜를 찾는다. 명시 날짜가 있으면 그것 | `9월 17일` · `9/16` · `10.7` · `9월 16일~18일`(14일까지 펼침) |
| 없으면 상대 표현 — 작성일 기준 | `오늘`·`금일` · `내일` · `다음 주 화요일` · `이번 주 목요일` · 그냥 `목요일`(작성일 이후 첫 목요일) · `이번 주 휴강`(그 주 전체) |
| 휴강 줄에 날짜가 없으면 같은 글 제목의 날짜 | 제목 '9월 17일 목요일 휴강' + 본문 '해당일 수업은 휴강할 예정' |
| 건너뛰는 것 | 부정(`휴강 없이` · `휴강 취소` · `휴강하지 않습니다` · `정상 수업`) · `보강…` 구절의 날짜 · `3.5학점` 같은 숫자 |
| 수업일에만 | 찾은 날짜가 그 과목 수업일이 아니면 걸지 않고, 날짜를 못 찾은 휴강 공지와 함께 카드에 **'확인 필요'**(공지 링크)로 띄운다 |

결과는 manifest 가 바뀔 때만 다시 읽는다(수정 시각·크기 캐시). 공지 휴강에는 학교 보강일을 붙이지 않는다 — 보강은 사용자가 추가한다.

## 계산 규칙 (요구사항정의서 F3 6절, 2026-09-29 수정)

| 단계 | 규칙 |
|---|---|
| 회 | **그 과목이 수업하는 날 하나 = 1회.** 같은 날 두 번 나뉜 수업(`월1월3`)도 1회 |
| 총 횟수 | 예정(시간표 × 개강~종강) − 휴강(자동: 학사일정·공지 / 내가 누름) + 보강(학교 지정 + 내가 추가) |
| 유효 결석 | 결석 횟수 + floor((지각 + 직접 조정 지각) ÷ 환산기준) + 직접 조정 결석. 공결·미입력은 세지 않는다 |
| 허용 · 남은 여유 | 총 횟수 × 한도 비율(기본 1/4) · 허용 − 유효 결석 · 더 빠질 수 있는 횟수 = floor(남은 여유) |
| 상태 | 총 0 → `—` / 유효 결석 > 허용 → **초과**(정확히 1/4 은 아직 아님) / 한 번도 안 빠짐 → 안전 / 남은 여유 < 1회 → **위험** / 허용의 절반 이상 → **주의** / 그 밖 안전 |
| 경고 | 과목마다 마지막으로 알린 단계를 두고 **올라간 순간 1회**(주의·위험·초과). 내려가면 기준도 내린다. 같은 단계는 10분 안에 다시 알리지 않는다(눌렀다 되돌리기 반복 대비) |

6절 예시(주 2회 × 15주, 휴강 1회, 결석 3회 + 지각 3회)는 `tests/test_calc.py` 에 그대로 있다: 총 29회 · 허용 7.25회 · 유효 결석 4회 → **주의**, 3번 더 빠질 수 있다.

## 회차와 기록

회차는 저장하지 않는다. **시간표(판별) × 학기 범위 + 보강** 으로 부를 때마다 만들고, 자동 휴강을 단 뒤 내 기록(`marks`: 출결·휴강·메모)을 회차 id 로 덧씌운다.
회차 id = `cl:<과목 id>:<날짜>` (보강은 끝에 `:mk`) — **캘린더의 수업 일정(C1 `kind=class`) id 와 같다** (F3-R14).

- 칩: 같은 칩을 다시 누르면 미입력(휴강이면 해제). 휴강인 회차에서 출결 칩을 누르면 휴강을 풀고 그 출결로 한 번에. 시작 전 수업은 공결·휴강만.
- 자동 휴강을 풀면(수업함) 근거는 남겨 '자동 휴강이었지만 수업함으로 바꿈'으로 보여 준다. 휴업일을 풀면 그 학교 보강일 회차는 빠진다.
- 시간표를 다시 가져와도 **내가 고친 시간표는 덮지 않는다**(자동/수정함 칩, F3-R02a). `자동값으로 되돌리기` 가 있다.
- 학기 중에 시간표가 바뀌면 **'오늘부터'** 새 판을 만든다 — 지난 회차·기록은 그대로 (F3-R17). 회차 id 가 날짜라 교시만 바뀌면 기록이 그대로 따라간다.
- 휴강으로 바꿔도 출결 기록은 지우지 않는다(풀면 다시 보인다). 맞는 날이 사라진 기록은 '떠 있는 기록'으로 남긴다.
- 누적 숫자 직접 수정(F3-R23)은 회차 기록과의 **차이만** `직접 조정` 으로 저장한다 — 가짜 결석 회차를 만들지 않는다.
- 옛 기록(2026-09-28 판, 회차 id 에 교시가 있던 것·조퇴)은 DB 를 처음 열 때 옮긴다(`store._migrate` — 조퇴는 지각으로).

## 대시보드와 잇는 법

`univ_us_local/backend/app/attendance.py` 가 이 폴더를 `sys.path` 에 넣고 `attendance.api.build_router(get_courses, get_profile, notify=…)` 를 include 한다.

- `/api/events` 에 수업 회차가 `kind: "class"` 로 섞인다(휴강 회차도 — 화면이 취소선·`휴강`/`휴강·자동` 꼬리표로 그린다). 캘린더는 **주·목록 보기**에서만 그린다.
- `/api/status` 의 `attendance` 칸(위험 과목 · 주의 · 확인 안 한 수업 · 시간표 미입력 · updatedAt)이 기능 타일을 채운다(F3-S08). `updatedAt` 은 내 기록과 e클래스 게시판 중 늦게 바뀐 시각 — 새 휴강 공지가 오면 화면이 다시 부른다.
- 상태가 올라가면 경고를 **대시보드 알림 센터**(F1 의 `notifications` 표, `kind: "attendance"`)에 넣고, 응답의 `alerts` 로 토스트도 띄운다(F3-S09).
- 폴더 위치가 다르면 백엔드에 환경변수 `F3_AGENT_DIR` 을 준다. 데이터는 `F3_DATA_DIR`·`F3_STATE_DIR`, 학사일정은 `F1_DATA_DIR`·`F1_AGENT_DIR`, e클래스(F6)는 `F6_AGENT_DIR`·`F6_DATA_DIR`.

## API (대시보드 `/api/docs`)

| 메서드 | 경로 | 내용 |
|---|---|---|
| GET | `/api/attendance/summary?semester=` | 학기(범위·휴업일·보강일) · 과목(설정·시간표·회차·집계·공지 확인 필요) · 합계 · 교시 시각 · 학사경고 |
