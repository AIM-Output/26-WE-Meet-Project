# F4_Textbook_agent — 강의자료 모으기·열람 (유니버스 F4 1차)

e클래스에서 **F6 가 내려받아 둔 강의자료·게시판 첨부·과제 첨부**를 이 폴더의 보관함으로 들여와 과목별 목록으로 세우고,
대시보드 안에서 **열어 보고 내려받게** 한다. 직접 가진 파일(교수님이 메일로 준 자료 등)도 끌어다 넣을 수 있다.

요구사항은 [요구사항정의서.md](../요구사항정의서.md) F4 절, 화면·라우트는 [Frontend-Route.md](../Frontend-Route.md) 9절.

> **1차 범위 = 자료를 모아 두고 열어 보는 것까지.**
> 요약·예상 문제·질문(RAG, F4-R03·R10~R34)은 모델·임베딩·벡터 DB 가 정해진 뒤 붙인다(미결 Q1~Q5, AI팀).
> 그 자리는 자료마다 `indexState` 한 칸으로 비워 두었고, 화면에서는 `분석 대기` 로 보인다.
> **1차에는 외부로 나가는 요청이 하나도 없다** — 동의(F4-R40)가 필요한 일은 인덱싱부터다.

- **파일을 새로 내려받지 않는다.** e클래스 수집은 [F6_Eclass_agent](../F6_Eclass_agent/README.md)(로그인은 [C3](../C3_Login_agent/README.md)) 가 하고,
  여기서는 `F6_Eclass_agent/data/manifest.json` 을 읽어 **파일을 `data/materials/` 보관함으로 들여온다**(2026-09-30 변경, 아래 "자료는 어디에 있나").
- **설치할 것이 없다** — 표준 라이브러리 + fastapi. 쪽수도 zipfile·zlib 로 직접 읽는다. 업로드도 multipart 가 아니다.
- 자료·목록은 `data/` 에만 있다. 밖으로 보내지 않는다 (F4-R40~R42). **이 폴더가 곧 강의자료 원본**이니 더더욱 공유 금지.

```
F4_Textbook_agent/
├── textbook/                파이썬 패키지
│   ├── config.py            경로(보관함·업로드·DB·F6 수집 폴더) · 허용 확장자 · 용량 · 상태 문구
│   ├── docmeta.py           쪽수 · 텍스트 유무 · 암호 · 내용 해시 (PDF·PPTX·DOCX, 표준 라이브러리만)
│   ├── store.py             SQLite 자료 목록 (data/textbook.db)
│   ├── catalog.py           보관함으로 들여놓기(하드링크·복사) + 자료 목록 맞추기 (새로·바뀜·내려감·중복)
│   ├── service.py           화면용 모양 · 과목 요약 · 직접 추가/삭제 · 파일 열기 경로 해석 (보관함에서 연다)
│   ├── api.py               FastAPI 라우터 (univ_us_local 이 include)
│   └── __main__.py          명령줄
├── tests/                   pytest 57개 (쪽수 읽기 · 종류·주차 · 스캔 · 보관 · 중복 · 업로드 규칙 · 삭제 규칙)
├── run.cmd                  보기 명령 (status · list · courses · scan · path)
└── data/                    (gitignore) — 절대 공유 금지
    ├── materials/           **강의자료 보관함** — <과목>/<활동>/<파일> (하드링크, 안 되면 복사)
    ├── uploads/             직접 추가한 파일 — <과목 id>/<파일>
    └── textbook.db          자료 목록 (쪽수·해시·상태)
```

## 자료는 어디에 있나 (2026-09-30)

**강의자료의 주인은 이 폴더다.** 스캔할 때 수집분을 `data/materials/<과목>/<활동>/<파일>` 로 들여놓고,
그 뒤로 화면이 여는 파일도 나중에 인덱싱할 파일도 전부 보관함 것이다.

| | |
|---|---|
| 들여놓는 방법 | **하드링크 우선, 안 되면 복사.** 같은 드라이브면 하드링크라 **디스크를 더 쓰지 않는다**(실측 43개 190MB → 추가 0). 다른 드라이브·파일 시스템이면 복사로 떨어진다 |
| F6 가 다시 받으면 | 같은 자리에 덮어쓰므로 하드링크는 내용이 그대로 따라오고, 복사본은 크기·시각이 달라진 것을 보고 다시 들여온다 (F4-R07) |
| F6 `data/` 를 지우면 | **보관본은 그대로 살아 있다.** F6 는 다음 수집 때 다시 받아 올 뿐이다 |
| 들여놓지 못하면 | (권한·디스크 문제 등) F6 자리를 그대로 가리킨 채 사유를 자료 줄에 적는다 — 자료가 안 보이는 것보다 낫다 |
| e클래스에서 자료가 내려가면 | 목록에서 지우지 않고 `내려감`(detached) 으로 남긴다. **이때만 사용자가 지울 수 있다** — 아직 올라와 있는 자료는 지워도 다음 스캔에 다시 들어오므로 막는다 |

## 쓰는 법

대시보드에서 **강의자료** 타일 → `/courses`. e클래스 동기화(F6)를 한 번 해 두면 과목마다 자료가 들어 있다.

명령줄:

```powershell
cd F4_Textbook_agent
.\run.cmd status                   # 자료 수 · 쪽수 · 종류별 · 수집 폴더 위치
.\run.cmd courses                  # 과목별 자료 수·쪽수
.\run.cmd list 오픈소스            # 자료 목록 (과목·파일 이름 일부로 거르기)
.\run.cmd scan --force             # 쪽수·해시까지 다시 읽기 (파일을 밖에서 바꿨을 때)
.\run.cmd path 오리엔테이션        # 실제 파일 경로 (탐색기에서 열 때)
```

테스트: `..\F1_Bachelor_agent\.venv\Scripts\python -m pytest tests -q`
(pytest 가 있는 아무 파이썬. 임시 폴더와 **가짜 수집 결과**를 쓰고 내 자료·e클래스에 닿지 않는다)

## 무엇을 자료로 보나

| 종류 | 어디서 온 것 | 예 |
|---|---|---|
| **강의자료** (`lecture`) | 과목의 자료 활동(`ubfile`·`resource`·`folder`) | `os04_process.pdf` |
| **게시판 첨부** (`board`) | 공지·자료실 글의 첨부 (F6 가 글과 함께 받아 둔 것) | `3주차 수업 자료` 글의 `4강 git.pdf` |
| **과제 첨부** (`assignment`) | 과제 설명에 붙은 양식·샘플 | `샘플_프로젝트정의서.hwp` |
| **직접 추가** (`upload`) | 내가 끌어다 넣은 파일 → `data/uploads/<과목 id>/` | 교수님이 메일로 준 보충자료 |

앞의 셋은 `data/materials/` 보관함으로 들여온다(위 "자료는 어디에 있나").

종류는 `courses.json` 의 활동 번호(cmid) → 모듈로 가르고, 모듈을 못 찾으면 경로(`게시판`·`과제`)로 본다.
동영상(vod)은 F6 가 아예 건드리지 않으므로 여기에도 없다 (복사방지 무력화 금지).

## 자료마다 읽어 두는 값

| 값 | 어떻게 | 왜 |
|---|---|---|
| 쪽수 | PDF 는 페이지 객체(`/Type /Page`)를 센다. 압축 xref 면 객체 스트림(`/Type /ObjStm`)만 풀어 다시 센다. 그래도 못 세면 `/Count`. PPTX 는 슬라이드 수, DOCX 는 `docProps/app.xml` | 화면 `13쪽` · 나중에 F5 학습 분량(F5-R10). **못 세면 `—`** — 틀린 숫자를 만들지 않는다 |
| 텍스트 유무 | 글꼴(`/Font`)이 하나라도 있는지 | 없으면 이미지만 있는 스캔본 → `텍스트 없는 PDF` 로 빼 둔다 (F4-R06). 2026-09-30 실측: 43개 중 2개 |
| 내용 해시 | sha256 | 파일이 바뀌면 다시 인덱싱(F4-R07), 같은 파일은 하나만(F4 8절) |
| 주차 | 이름에서 추정 — `3주차` `5주.` `4강` `Week2` `2-1_…` `os04_…` | 범위 선택(F4-R14)의 기본값. **추정이라고 화면에 밝힌다** |

크기·수정 시각이 그대로면 다시 읽지 않는다. 43개 자료(190MB) 첫 스캔 0.45초, 그다음은 25ms,
`manifest.json` 과 업로드 폴더가 그대로면 아예 훑지 않는다.

## 상태 (`indexState`)

| 값 | 화면 | 뜻 |
|---|---|---|
| `pending` | 분석 대기 | 인덱싱 파이프라인이 붙으면 대상 (1차에서는 전부 여기) |
| `ocr_needed` | 텍스트 없는 PDF | 글자가 없는 이미지 PDF — 요약·문제에서 제외 (F4-R06). 열람은 된다. **'확인 필요'로 세지 않는다** — 할 수 있는 조치가 없다 (2026-10-01) |
| `locked` | 열 수 없음 (암호) | 암호 걸린 PDF — 열람은 되고 분석만 못 한다 |
| `unsupported` | 분석 제외 | `.zip` 등 분석 대상이 아닌 확장자 (목록·열람은 된다) |
| `duplicate` | 중복 파일 | 같은 내용이 이미 있다 — 하나만 인덱싱 |
| `missing` | 파일 없음 | 보관본도 원본도 없다. 목록에서 지우지 않고 표시만 한다(동기화하면 다시 들여온다) |
| `running`·`done`·`failed` | 분석 중·준비됨·분석 실패 | (인덱싱이 붙은 뒤) |

## API (univ_us_local 이 붙인다)

| 메서드 · 경로 | 하는 일 |
|---|---|
| `GET /api/materials?course=&kind=&q=` | 과목 요약 + 자료 목록 (F4-S01·S02) |
| `GET /api/materials/status` | 가벼운 상태 — 자료 수·쪽수·마지막 스캔 (기능 타일·폴링) |
| `POST /api/materials/scan?force=1` | 수집 폴더 다시 훑기 |
| `POST /api/materials?course=&name=` | 직접 추가 — **요청 본문이 파일 그대로** |
| `GET /api/materials/{id}` | 자료 하나 (같은 활동의 다른 파일·중복 여부·보관 경로·원본 경로) |
| `DELETE /api/materials/{id}` | 직접 추가분과 `내려감` 보관본만 삭제 (e클래스에 아직 있는 자료는 409) |
| `GET /api/materials/{id}/file?download=1` | 원문 열기(inline) / 내려받기(attachment). Range 지원 |

업로드가 multipart 가 아닌 이유: 백엔드 `.venv` 에 `python-multipart` 를 더 깔지 않으려고
`fetch(url, {method:'POST', body: file})` 로 받는다. 파일 이름·과목은 쿼리로 온다.

## 지키는 선 (학교 공지 「저작권 유의사항 안내」 · F4-R40~R42)

| 금지 | 이 도구의 대응 |
|---|---|
| 자료를 타인에게 배포·전송 | `data/` 는 `.gitignore`. **공유·내보내기 기능이 없다.** 파일을 넘겨주는 상대는 127.0.0.1 의 내 대시보드뿐 |
| 인터넷 게시 | 서버는 127.0.0.1 에만 바인딩하고 Host·Origin 을 막는다 (univ_us_local) |
| 복사방지 무력화 | 동영상은 목록에도 없다 (F6 가 요청조차 하지 않는다) |

파일은 **자료 id 로만** 연다 — 경로를 받지 않고, 해석한 경로가 수집 폴더·업로드 폴더 밖이면 거부한다.

## 다음 차례 (AI팀 정해지면)
