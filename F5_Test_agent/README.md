# F5_Test_agent — 시험 공부 일정 자동 추천 (유니버스 F5)

시험일과 자료 분량을 보고 **"오늘 몇 쪽을 봐야 하는지"** 를 역산해 캘린더에 학습 블록으로 넣어 준다.
시험 일정은 **e클래스 공지에서 찾고**(F6 가 모아 둔 글), 분량은 **강의자료(F4)의 쪽수 합계**를 기본값으로 쓴다.

요구사항은 [요구사항정의서.md](../요구사항정의서.md) F5 절, 화면·라우트는 [Frontend-Route.md](../Frontend-Route.md) 10절.

> 시험 3일 전에 200쪽이 남아 있다는 걸 **3일 전에 안다**. 분량을 날짜로 나누는 계산을 아무도 미리 하지 않는다.
> 이 기능의 신뢰도는 **미리보기**가 만든다 — 계획을 캘린더에 넣기 전에 "하루에 이만큼"을 눈으로 확인시킨다.

- **설치할 것이 없다** — 표준 라이브러리 + fastapi(라우터에만). 계산은 규칙 기반 코드이고 **LLM 을 부르지 않는다**(F5-R26).
  공지에서 시험을 찾는 일도 정규식으로 한다 — 2026-09-30 실측 공지 18건에서 시험·발표 3건을 다 찾았다.
- **파일을 내려받지 않는다.** e클래스 수집은 [F6_Eclass_agent](../F6_Eclass_agent/README.md)(로그인은 [C3](../C3_Login_agent/README.md)) 가 하고,
  여기서는 `F6_Eclass_agent/data/manifest.json` 과 게시판 글(.md)을 **읽기만** 한다.
- 시험·계획·진도는 `data/exams.db` 에만 있다. 밖으로 보내지 않는다 (F5 9절).
- **등록은 사용자가 미리보기를 확인한 뒤에만** 한다 (F5 D3). 계산만으로 캘린더가 바뀌는 길은 없다.

## 계산 규칙 (F5 5절)

```
학습 가능일  = 시작일(기본 오늘) … 시험 전날
  − 마무리 복습일 R (중간·기말 2일 / 퀴즈·발표·기타 1일, 설정 가능)   ← 가능일의 끝쪽에서 뗀다
  − 사용자 제외일                                                  ← 0쪽으로 두고 나머지에 재분배
  = 학습일 D

총 분량      = Σ(범위 내 F4 자료 쪽수)    ← 없으면 사용자가 쪽 또는 분으로 직접 입력
쪽당 시간    = 난이도 계수 (쉬움 1 / 보통 1.5 / 어려움 2분 (설정에서 바꿈))
하루 분량    = ceil(총 분량 ÷ D)          ← 균등 분할, 반올림 오차는 **마지막 날이 흡수**한다
마무리 복습일 = 전체 훑기(총 시간 × 0.3 ÷ R) + (선택) 예상 문제 풀이(문항당 2분)
```

| 판정 | 언제 | 화면 |
|---|---|---|
| `ok` | 하루 시간 ≤ 상한(기본 4시간) | 그대로 등록 |
| `over` | 하루 시간 > 상한 | 빨강 띠 + **조정안 3가지**. 넘쳐도 등록을 막지는 않고 확인을 한 번 더 받는다 |
| `overlap` | 다른 과목 계획과 합쳐 상한 초과 | 어느 날 어느 과목이 몰렸는지 + 재분배 제안 |
| `no_time` | 학습일 D ≤ 0 (시험이 오늘·내일) | 계획 대신 "남은 시간에는 요약과 예상 문제를" |

조정안은 **넘친 곳에 맞는 것**만 준다 — 학습일이 넘쳤으면 `분량 줄이기`·`제외일 지우기`, 마무리 복습일이
넘쳤으면 `복습일 늘리기`·`예상 문제 줄이기`, 그리고 언제나 마지막에 `하루 상한 올리기`.
`분량 줄이기`가 제안하는 쪽수는 **학습일과 복습일 둘 다** 상한 안에 들어오는 값이라, 눌렀는데 경고가 그대로 남지 않는다.

> 요구사항정의서 5절 예시 그대로: 10/23 중간고사 · 오늘 10/13 · 120쪽 · 보통
> → 가능일 10일 − 복습 2일 = **학습일 8일** · 하루 **15쪽 (38분)** · 10/21~10/22 전체 복습. (`tests/test_plan.py`)

## 공부 캘린더 (F5-S11, 2026-10-01)

시험 공부만 보는 캘린더 — `/exams` 의 **공부 캘린더** 버튼, 또는 대시보드 서버의 `/study-calendar`.
화면 파일은 이 폴더의 `web/study_calendar.html` 한 장이고(바깥 라이브러리 없음), 데이터는 `GET /api/study-calendar?start=&end=`.

- 날짜마다 **과목 · 시각 · 쪽 · 시간**(`운영체제 19:00 59쪽 · 2시간 28분`)과 그날 합계, 그날의 시험
- 날짜가 확정되지 않은 시험(임의 일정·확인 필요)도 **점선·?** 로 보인다 — 전체 캘린더에는 안 들어간다
- **공부 계획(학습 블록)은 이 캘린더에만 나온다** — 전체 캘린더(대시보드)에는 날짜가 확정된 시험만 들어간다 (2026-10-01)
- 날짜를 누르면 위 '오늘 공부' 패널이 그날로 바뀌고, 체크하면 완료로 저장된다 — **체크를 풀 수도, `삭제`로 지울 수도** 있다(완료한 것도, 2026-10-02)
- 좁은 화면(720px 밑)은 목록으로 연다 · 1분마다 다시 읽는다

## 계획 옵션 — 날짜가 주 옵션 (F5-R15, 2026-10-01)

- **학습일 N일** → 마무리 복습 바로 앞 N일에 나눈다. 바로 옆에 `하루 N쪽 · M시간`이 보인다
- 달력에서 날짜를 눌러 **직접 고를** 수 있다(고른 날 그대로 등록된다, `자동으로`로 되돌림)
- 분량은 쪽수로만 받는다(시간(분) 단위는 화면에서 뺐다 — 명령줄 `--minutes` 는 남아 있다)
- **마무리 복습 기본값은 시험 전날 하루**(모든 유형), **하루 상한은 옵션이 아니다** — 4시간 기준 경고만 한다 (2026-10-02)
- **난이도 시간 설정**(`/exams` 헤더): 쪽당 쉬움 1 · 보통 1.5 · 어려움 2분이 기본(위아래 버튼 0.5분씩), 바꾸면 앞으로 만드는 계획에 쓰인다
- **학습일 기본 3일** — 마무리 복습 바로 앞 3일. 칸을 지우고 다시 칠 수 있고, 비운 채로 떠나면 원래 값으로 돌아간다
- 넘치면 조정안 첫째가 '학습일 늘리기'

## 과목마다 중간·기말 — 임의 일정 (F5-R07~R09, 2026-10-01)

**모든 과목은 중간고사·기말고사 2회를 본다고 둔다.** 시험이 없는 과목은 `/exams` → `과목별 시험`에서 끈다(퀴즈·발표는 따로 — 공지·직접 추가).

일정이 아직 안 나온 시험은 이렇게 **임의로** 잡는다 (`source='auto'`, 화면에 점선 `임의 일정`):

| | 중간고사 | 기말고사 |
|---|---|---|
| 언제 만드나 | 학기 시작 (중간 수업평가 기간이 아직 안 끝났으면) | **그 과목의 중간고사 날짜가 지나면** (중간이 없는 과목은 중간 수업평가 기간이 끝나면) |
| 기간 | 학사일정 `제N학기 중간 수업평가` | `제N학기 최종 수업평가` (종강까지로 자른다) |
| 고르는 날 | 그 안의 공식 `중간고사` 주간의 **첫 수업** | 공식 `기말고사` 주간의 **첫 수업** |
| 시각 | 그 수업의 시각 (F3 시간표) — 시간표가 없으면 그 주 첫 평일·시각 미정 | 같음 |

- 이른 날을 고르는 이유: 계획을 이른 날짜에 맞춰 두면 실제 시험이 늦을 때 여유가 생기고, 반대면 준비가 안 된다.
- **공지에서 일정이 나오면 그 자리가 바뀐다** — 중간·기말의 id 가 (과목, 유형)이라 같은 시험의 갱신이 된다. 화면엔 `일정 확정`, 알림은 "일정이 나왔습니다".
- 사용자가 날짜·시각을 고치면 직접 넣은 일정이 된다(공지가 덮어쓰지 않는다). 범위만 넣었으면 임의 일정 그대로(공지가 날짜를 채운다).
- 임의 일정을 지우면 = 그 과목은 그 시험을 안 본다 → 과목 설정이 꺼진다.
- 시간표가 나중에 바뀌면 다시 잡는다 — **계획을 등록한 시험은 옮기지 않는다**.
- 임의 일정에도 공부 계획을 그대로 만들 수 있다.
- 학사일정에 기간이 없으면 만들지 않는다(날짜를 지어내지 않는다).
- **임의 일정·확인 필요 시험은 전체 캘린더(/api/events)에 넣지 않는다** — 시험 화면과 공부 캘린더에만 보인다.
- 발표·시험의 **시각 미정은 그 과목 수업 시간**으로 채운다(그날 수업 > 같은 요일 > 첫 수업, 화면에 '(수업 시간)').

2026-10-01 실측: 7과목 중 6과목에 임의 중간고사(10/19 월~10/21 수, 각 과목 첫 수업 시각), 소프트웨어공학론은 공지 일정(10/22 목 15:00) 그대로.

```powershell
.\run.cmd courses                              # 과목별 시험 유무 + 중간·기말 상태
.\run.cmd course 산학협력 --no-midterm --no-final   # 시험이 없는 과목 끄기 (--midterm/--final 로 켜기)
.\run.cmd defaults --date 2026-10-24           # 그날인 것처럼 임의 일정을 맞춰 보기 (기말 생성 확인)
```

## 공지에서 시험 찾기 (F5-R01·R02)

글 하나에서 '언제'를 고르는 순서 — **2026-09-30 실측 공지로 맞췄다**(`tests/test_notices.py` 가 그 세 글을 지킨다).

1. 시험말(중간고사·기말·퀴즈·발표·시험)**과 날짜가 같은 줄** → `- 09월 16일: 기획서 발표` → 9/16 발표
2. 줄머리가 **일시·일정·날짜·시험일** 이름표 → 제목 `중간고사 장소 및 준비물 공지` + `1. 일정: 10월 22일 목요일 오후 3시부터 4시까지`
   → **10/22 15:00~16:00 중간고사 · 박물관 시청각실**
3. 제목의 날짜 → 4. 본문에 날짜가 딱 하나면 그것(신뢰도를 깎는다)

- **'범위' 줄 · '제출·마감' 줄 · '작년·지난 학기' 줄의 날짜는 시험일이 아니다** — `4. 시험 범위: 10월 15일 까지` 는 범위 문구로만 쓴다.
- `발표 일정이 없습니다` · `시험 취소` 처럼 부정하는 줄은 건너뛴다.
- 시험을 말하는데 날짜를 못 찾으면 **조용히 버리지 않고** '확인 필요'에 링크로 남긴다.
- 신뢰도 0.75 미만이면 `status: review` → 화면의 **확인 필요 카드**로 간다. 근거 원문은 항상 볼 수 있다 (F5 9절 '신뢰').
- 재수집해도 **사용자가 고친 것은 덮어쓰지 않고**(`edited`), **지운 것은 되살리지 않는다**(`removed_at`).
  중간·기말은 과목마다 하나라 id 에 날짜를 넣지 않는다 → 날짜가 바뀌면 **같은 시험의 연기**로 감지해 알린다 (F5 8절).
- 같은 과목·같은 날짜에 수기 시험이 있으면 **수기가 이긴다**.

## 캘린더에 넣는 것 (C1 3절)

| | `kind` | id | 색 | 편집 |
|---|---|---|---|---|
| 시험 | `exam` | `ex:<과목>:<해시8>` | `#B91C1C` | 불가 (원천은 공지·수기) |
| 학습 블록 | `study` | `st:<계획>:<날짜>` | `#4D7C0F` | 이동·삭제·완료 체크 |

- 시각이 없는 시험은 **종일 일정**으로 들어간다(`end` 는 exclusive, C1-R14).
- 학습 블록의 **시간대는 F8(공강 학습 플랜) 몫**이다. F8 이 붙기 전까지만 F5 가 기본 시간대(19:00)에 넣는다 (F5-R37).
  블록에 `placedBy: "f5-default"` 를 달아 두었으니 F8 이 그 값을 보고 다시 배치하면 된다.
- 블록을 다른 날로 옮길 수 있고, **이미 분량이 있는 날로 옮기면 그 날에 합친다** — 블록이 사라지거나 둘이 되지 않는다.
  완료한 날로는 옮기지 못한다.
- 계획을 취소하면 **미완료 블록만** 지운다. 완료한 블록은 캘린더에 남는다 (F5-R35).
- 시험일이 지나면 계획을 `done` 으로 닫는다. 끝난 계획의 블록은 **완료한 것만** 캘린더에 그려지므로 유령 블록이 남지 않고,
  못 한 것은 진도 화면에 기록으로 남는다 (F5 8절).

## 쓰는 법

대시보드에서 **시험** 타일 → `/exams`. e클래스 동기화(F6)를 해 두면 공지에서 찾은 시험이 이미 들어와 있다
(대시보드가 상태를 부를 때 공지 목록이 바뀌었으면 알아서 다시 읽는다 — `service.ensure_sync`).
화면에서는 시험 카드의 `계획 만들기` → 오른쪽 패널에서 **옵션 → 미리보기 → 등록** 세 단계로 진행한다
(주소에 `?exam=&step=` 이 남아 중간에 나갔다 와도 그 자리에서 이어진다).

명령줄:

```powershell
cd F5_Test_agent
.\run.cmd sync                       # e클래스 공지에서 시험 찾기 (넣거나 갱신)
.\run.cmd status                     # 시험 목록 · D-day · 범위·쪽수 · 계획 상태 · 오늘 분량
.\run.cmd notices                    # 공지에서 읽힌 것만 보기 (저장하지 않는다)
.\run.cmd scope 소프트웨어공학론 --weeks 1-5     # 범위 안 자료 쪽수 (F4)
.\run.cmd preview ex:74261:302a3b78 --difficulty hard --cap 180 --exclude 2026-10-15
.\run.cmd plan ex:74261:302a3b78 --weeks 1-5 --quiz 20            # 등록 (캘린더에 학습 블록)
.\run.cmd progress                   # 진도 · 밀림
.\run.cmd done pl:1 2026-10-13       # 완료 체크 (--undo 로 되돌리기)
.\run.cmd rebalance pl:1             # 밀린 진도를 남은 날로 다시 나눈 미리보기
.\run.cmd cancel pl:1                # 계획 취소 (미완료 블록만 지운다)
.\run.cmd events --from 2026-10-01 --to 2026-10-31   # 캘린더에 나갈 일정
```

시험을 직접 넣기:

```powershell
.\run.cmd add 소프트웨어공학론 midterm 2026-10-22 --time 15:00 --place "박물관 시청각실" --weeks 1-7
```

## API (univ_us_local 이 붙인다)

| 시점 | 호출 |
|---|---|
| 시험 목록 | `GET /api/exams?semester=&sync=1` |
| 시험 추가 | `POST /api/exams` |
| 공지에서 다시 찾기 | `POST /api/exams/sync` |
| 오늘 분량 (F10·F9) | `GET /api/exams/today` |
| 과목별 시험 유무 | `GET /api/exams/courses` · `PATCH /api/exams/courses/{courseId}` `{midterm?, final?}` |
| 공부 캘린더 | `GET /api/study-calendar?start=&end=` · 화면 `GET /study-calendar` |
| 난이도 시간 설정 | `GET·PUT /api/exams/settings` `{difficulty: {easy, normal, hard}}` (분/쪽, null = 기본값) |
| 학습 블록 지우기 | `DELETE /api/study-plans/{id}/days/{date}` (완료한 것도, 마지막이면 계획도) |
| 시험 하나 + 계획 옵션 기본값 | `GET /api/exams/{id}` |
| 승인·수정 / 삭제 | `PATCH` · `DELETE /api/exams/{id}` |
| **계획 계산 (저장 안 함)** | `POST /api/study-plans/preview` |
| **계획 등록** | `POST /api/study-plans` |
| 계획 + 진도 + 범위 자료 | `GET /api/study-plans/{id}` |
| 재조정 미리보기 | `POST /api/study-plans/{id}/rebalance` |
| 계획 취소 | `DELETE /api/study-plans/{id}` |
| 학습 블록 하나 + 그날 볼 자료 | `GET /api/study-plans/{id}/days/{date}` |
| 완료 체크 · 다른 날로 옮기기 | `PATCH /api/study-plans/{id}/days/{date}` |

미리보기와 등록을 나눈 이유: 같은 계산기를 두 번 쓰되 **등록만 부수효과**를 갖게 해서, 화면이 '계산 결과'와
'실제 캘린더'를 헷갈리지 않게 한다. 조정안의 `apply` 를 미리보기 본문에 그대로 덮어 다시 부르면 된다.

시험 연기·진도 밀림은 대시보드 알림 센터(F1 `notifications`, `kind='exam'`)로 들어간다.
따로 도는 스케줄러가 없다 — 대시보드가 상태를 부를 때(1분) 지난 계획을 닫고 밀림 알림을 배달한다.

## 아직 안 한 것

| | |
|---|---|
| ~~화면~~ | ~~`/exams` 페이지는 아직 예시 데이터다~~ → **2026-10-01 연결 완료**: `/exams` 목록·옵션·미리보기·진도, 캘린더의 시험·학습 블록 상세, 대시보드 `오늘 공부` 타일 (Frontend-Route 10절) |
| 예상 문제 | 마무리 복습일에 **문항 수와 시간만** 잡아 둔다. 실제 문제는 F4 의 요약·문제 생성(RAG)이 붙은 뒤에 이어진다 (F5-R13, 미결 Q4) |
| 간격 반복 | 1차는 균등 분할 + 마무리 복습만 (F5 D4, 미결 Q5) |
| 학사일정의 시험기간 | 후보 날짜로 제안하지 않는다 — 과목별 날짜가 아니기 때문이다 (F5 D1, 미결 Q1) |

시범 사용 뒤에 다시 볼 숫자(요구사항정의서 F5 10절): 쪽당 시간 1.5/2.5/4분(Q2) · 하루 상한 4시간(Q3) ·
문항당 2분(Q4) · 마무리 복습 훑기 비율 0.3(요구사항에 숫자가 없어 1차 값으로 둔 것).
