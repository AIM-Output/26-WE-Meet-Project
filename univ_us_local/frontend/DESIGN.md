# 디자인 시스템: 유니버스 Univ-Us v3 "Paper & Pine"

2026-10-07 재디자인. 브랜드 두 색 **베이지 `#CBAF94`** 와 **다크그린 `#33644D`** 를 바탕으로 v2(틸·주황)를 바꿨다.
**다크 모드는 두지 않는다** (2026-10-08 사용자 결정 — 웹·데스크톱 앱 모두 라이트 하나. 시스템이 다크여도 종이색 그대로).
토큰의 실제 값은 `src/app/globals.css` 에 있고, 이 문서는 그것을 사람이 읽기 좋게 옮긴 것이다. **값을 바꿀 때는 두 곳을 같이 고친다.**

## 1. 분위기 (Visual Theme & Atmosphere)

녹색 잉크로 쓴 공책을 베이지 종이 위에 펼쳐 둔 느낌. 바탕은 모래빛이 아주 옅게 도는 종이와 고운 결(grain)이고, 카드는 그 위에 놓인 한 장의 종이다. 색은 녹색 하나로 아끼고, 상태색은 채도를 낮춘 파스텔로 꼭 필요할 때만 쓴다.

| 다이얼 | 값 | 뜻 |
|---|---|---|
| 밀도 (Density) | 6 — Daily App Balanced | 매일 여는 대시보드. 숫자·목록이 많아 여백보다 정리가 우선 |
| 변화 (Variance) | 4 — Offset Asymmetric | 왼쪽 정렬 날짜 + 오른쪽 숫자 쟁반, 본판(캘린더) 하나만 겹테로 강조 |
| 움직임 (Motion) | 4 — Fluid CSS | 상태 변화·피드백에만. 계속 도는 장식 애니메이션 없음 |

## 2. 색과 역할 (Color Palette & Roles)

- **Paper** (`#F8F4F0`) — 페이지 바탕. 베이지를 14% 로 연하게 깐 종이. 위쪽에서 모래빛(`rgba(203,175,148,.34)`)이 비친다
- **Sheet** (`#FFFDFA`) — 카드·모달·입력. 순백 대신 아주 따뜻한 흰색
- **Hover Sheet** (`#FAF6F1`) / **Sand Tray** (`#F2EBE3`) — 마우스 올림 / 칩·탭 트랙·쟁반
- **Hairline** (`#E7DFD5`) / **Hairline Strong** (`#D4C8B9`) — 따뜻한 1px 테두리 / 올렸을 때
- **Pine Ink** (`#1F2B25`) — 본문 글자. 순검정 금지, 녹색이 도는 먹색
- **Moss Gray** (`#4B524D`) / **Lichen Gray** (`#646B66`) — 보조 글자 / 날짜·메타
- **Pine** (`#33644D`, 올림 `#2B5441`, 연하게 `#E9F0EC`·`#D2DDD8`) — **유일한 브랜드 강조색**. 주요 버튼·포커스·선택·오늘 표시
- **Sand** (`#CBAF94`, 연하게 `#F3EBE2`, 글자용 `#7A5C40`) — 두 번째 브랜드 색. 강조가 아니라 **바탕의 결**: 쟁반·선택 영역·로고 글자·보조 표기
- **Terracotta** (`#B4532A`, 글자용 `#9C441F`, 연하게 `#F8E9E0`) — 상태색 '임박·할 일'. 브랜드 강조가 아니다
- 상태 파스텔 (글자 / 배경): **위험** `#9F2F2D`/`#FBECEB` · **주의** `#8A5D00`/`#FAF1D9` · **완료** `#3A6B3E`/`#ECF2E8` · **정보** `#1F6C9F`/`#E6F1F8` · **학습** `#5C6B22`/`#EFF1E0`

## 3. 글자 (Typography Rules)

- **본문·한글:** **Pretendard Variable** (npm 로컬 번들 — 오프라인에서도 같은 글꼴). 16px · 행간 1.55
- **숫자·영문 표시:** **Plus Jakarta Sans** (`.num` — `tabular-nums`). D-day·학점·시각·통계
- **고정폭:** 시스템 mono (`kbd` 단축키)
- **제목:** 굵기와 색으로 위계를 만든다. 대시보드 날짜 30→40px / 800 / 자간 −0.03em, 요일만 Pine 색. 페이지 제목 24→28px / 700. `text-wrap: balance`
- **금지:** Inter · 세리프(대시보드에는 쓰지 않는다 — 한글 본문과 섞이면 가독성이 떨어진다)

| 역할 | 크기 / 굵기 |
|---|---|
| 대시보드 날짜 | 30→40px / 800 |
| 페이지 제목 | 24→28px / 700 |
| 섹션·모달 제목 | 15~19px / 700 |
| 본문 | 16px / 400 |
| 목록 행 제목 | 14~15px / 600 |
| 보조·메타 | 12~13px |
| 칩 | 12px / 700 |

## 4. 부품 (Component Stylings)

* **헤더:** 화면 위에 붙지 않는 **떠 있는 섬** — 위 여백 12px, 모서리 22px, 반투명 종이(80%) + 흐림, 따뜻한 그림자. 흐림은 이 고정 층에만 쓴다. 로고는 Pine 사각형 + Sand 글자
* **버튼:** 모서리 10px(작게 8px). 주요 버튼은 Pine 채움 + 위쪽 옅은 빛(inset highlight). 누르면 1px 내려가며 0.985 로 줄어든다. 바깥 빛(glow) 없음
* **카드:** 종이 한 장 — 따뜻한 1px 테두리 + 아주 옅은 그림자 + 위쪽 안쪽 빛. 눌러 들어가는 카드만 올리면 1px 떠오르며 그림자가 퍼진다
* **겹테(double bezel):** 바깥 모래빛 쟁반(패딩 6px, 모서리 22px) + 안쪽 종이(16px). **대시보드 캘린더 본판과 오늘 숫자 쟁반에만** 쓴다 — 아무 데나 쓰면 위계가 사라진다
* **칩·배지:** 상태는 둥근 알약(999px) 파스텔 + 아이콘 + 글자. 정보 표기(유형 등)는 7px 모서리
* **입력:** 라벨은 위, 오류는 아래. 포커스는 Pine 테두리 + 3px 링. 선택 상자 화살표도 보조 글자색
* **로딩·빈 화면·오류:** 레이아웃 모양 그대로의 스켈레톤(쟁반색 반짝임), 아이콘 + 한 줄 + 다음 행동 버튼, 패널 안에 가두는 오류
* **토스트:** Pine Ink 바탕에 종이색 글자
* **모서리 규칙(Shape lock):** 칩 999 · 작은 버튼 8 · 버튼·입력·행 10 · 카드·목록 16 · 모달·헤더 섬·쟁반 22 — Tailwind `rounded-md/lg/xl/2xl` 을 이 값으로 다시 정의했다

공용 부품 파일은 `src/components/ui` (Chip · Feedback · Modal · Toast · Progress · Tabs · Layout · WeekGrid).

## 5. 배치 (Layout Principles)

- 대시보드 최대 폭 1600 · 기능 페이지 1200(넓은 화면 1440) · 좌우 16(폰) / 40(md+)
- 대시보드 첫 줄은 **비대칭**: 왼쪽 큰 날짜, 오른쪽 숫자 쟁반(오늘 일정 · 3일 안 마감 · 과목)
- 3단 `300px | 1fr | 300px` (≥1280) → 캘린더 위 + 2단 (768~1279) → 1단(캘린더 → 실행 → 할 일). 폰에서 가로 스크롤 금지
- 바탕 결(grain)은 `body::before` 고정 층(포인터 없음, z −1) — 스크롤 영역에 붙이지 않는다. 카드가 불투명이라 글자 위에는 결이 깔리지 않는다
- sticky 오프셋은 `--header-h`(76px, 떠 있는 헤더 전체 높이) 하나로 맞춘다

## 6. 움직임 (Motion & Interaction)

- **엔진:** `motion/react` + CSS transition. 루트에 `MotionConfig reducedMotion="user"` — 움직임 줄이기를 켜면 transform·layout 애니메이션이 꺼지고 투명도만 남는다
- **곡선:** CSS 는 `--ease-out` `cubic-bezier(0.16,1,0.3,1)` · `--ease-soft` `cubic-bezier(0.32,0.72,0,1)`. Motion 은 스프링(bounce 0, visualDuration 0.2~0.3s). linear·기본 ease-in-out 금지
- **원칙:** 움직임은 상태 변화·관계·피드백에만. 퇴장은 등장보다 빠르게(≈120ms). transform·opacity 만 움직인다
- 계속 도는 장식 루프(pulse·float 등)는 쓰지 않는다. 진행 중 표시(스피너·스켈레톤)만 예외

## 데스크톱 앱 (`desktop/`)

대시보드는 같은 `frontend/out` 을 창에 띄우므로 그대로 따라온다. 앱에만 있는 세 곳도 같은 디자인으로 맞췄다.

- **시작 화면** `desktop/splash/index.html` — 종이 바탕 + 결 + Pine 로고 사각형(Sand "U") + 왕복하는 진행 띠. 오류 문구가 오면(main.rs `show_status`) 진행 띠를 멈추고 위험 파스텔 상자로 바꾼다
- **창 바탕색** `src-tauri/src/main.rs` `PAPER #F8F4F0` — 시작 화면 → 대시보드로 넘어갈 때 흰색이 번쩍이지 않게
- **앱 아이콘** `src-tauri/icons/make_source.py` — 다크그린 둥근 사각형 + 베이지 "U" (헤더 로고와 같은 배색) → `npm run icon` 으로 모든 크기. 생긴 `android/`·`ios/` 폴더는 쓰지 않아 지운다

## 7. 쓰지 않는 것 (Anti-Patterns)

- 다크 모드·테마 전환 (사용자 결정 2026-10-08)
- 이모지 아이콘 · Inter · 대시보드 세리프 · 순검정 `#000` · 순백 큰 면
- 브랜드 강조색 두 개 이상 (녹색 하나. 베이지는 결, 테라코타는 상태색)
- 차가운 회색과 따뜻한 회색 섞기 — 회색은 모두 잉크(`#1F2B25`)와 종이(`#F8F4F0`) 사이에서 뽑는다
- 검정 그림자 · 바깥 빛(glow) · 네온 · 큰 그라데이션 글자
- 화면 위에 붙은 전체 폭 헤더 · 모든 카드에 겹테
- 컴포넌트에 HEX 직접 쓰기 (데이터에서 오는 과목·분류 색만 예외) — 새 색은 토큰부터
- 색만으로 상태 전달 (글자·아이콘 병기) · 포커스 링 지우기
