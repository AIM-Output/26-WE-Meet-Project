# Univ-Us 디자인 시스템 v2

2026-09-27 전면 재작성. `ui-ux-pro-max` 스킬의 추천(제품 유형: Productivity Tool · Calendar & Scheduling)을 바탕으로 정했다.
토큰의 실제 값은 `src/app/globals.css` 의 `:root` 에 있고, 이 문서는 그 표를 사람이 읽기 좋게 옮긴 것이다. **값을 바꿀 때는 두 곳을 같이 고친다.**

| 항목 | 결정 | 근거 |
|---|---|---|
| 스타일 | **Flat Design + Micro-interactions** (보조: Minimalism) | 생산성·캘린더 앱 1순위 추천. 선과 여백 중심, 그림자는 떠 있는 층(모달·팝오버·토스트)에만 |
| 주색 | 틸 `#0F766E` | 교육·생산성 팔레트. 흰 글자 대비 5.5:1 (스킬 추천 `#0D9488` 은 3.7:1 이라 한 단계 어둡게) |
| 강조(CTA) | 주황 `#EA580C` / 글자용 `#C2410C` | 할 일·마감·"먼저 할 것" — 기존 "할 일 = 주황" 규칙 유지 |
| 글꼴 | 본문 **Pretendard Variable**(로컬 번들) · 숫자·영문 표시 **Plus Jakarta Sans** | 한글 가독성 + 스킬 추천 SaaS 페어링. Pretendard 는 npm `pretendard` 로 묶어 오프라인에서도 같은 글꼴 |
| 아이콘 | **lucide-react** 선 아이콘(이모지 아이콘 금지) | 스킬 체크리스트 "No emojis as icons" |
| 움직임 | **motion** (`motion/react`) · 150~300ms · 스프링 bounce 0 | `MotionConfig reducedMotion="user"` 로 움직임 줄이기 설정 존중 |

## 치수

- 여백 4의 배수. 페이지 좌우 16(폰) / 40(md+), 대시보드 최대 폭 1600, 기능 페이지 1200(넓은 화면용 1440)
- 라운드: 칩 999 · 작은 버튼·입력 6 · 버튼·입력 8 · 카드 12 · 모달 16
- 버튼 40 / 작게 32 (터치 기기에서는 최소 44), 입력 42 / 작게 32, 칩 24, 헤더 64
- 대시보드 3단: `300px | 1fr | 300px` (≥1280) → 캘린더 위 + 2단 (768~1279) → 1단(캘린더 → 실행 → 할 일)

## 규칙

1. 상태는 색만으로 전하지 않는다 — 칩·배지에 글자와 아이콘을 함께.
2. 포커스 링은 지우지 않는다(`:focus-visible` 2px 주색).
3. 새 색이 필요하면 토큰을 먼저 만든다. 컴포넌트에 HEX 를 직접 쓰지 않는다(과목·분류 색처럼 데이터에서 오는 값만 예외).
4. 움직임은 상태 변화·관계·피드백에만. 장식용 애니메이션 금지, 퇴장은 등장보다 빠르게(120ms 안팎).
5. 백엔드 API 가 없는 화면은 `<DemoNotice />` 로 "예시 데이터"를 늘 표시한다.
